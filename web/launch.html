STEP 2 // SPLIT

Set the split

pump pays a share of every trade to the coin’s creator vault. This split decides where that share goes, and it is set once.

The protocol row

Fixed at 0.25% of each transaction. It buys and burns $CHARLIE, and it is what makes this coin part of Charlie Protocol. You cannot edit it.

Your rows

Share the rest and must total 100%. The incinerator row is fixed: SOL sent to it is destroyed, and you choose how much, from 1% up. Every other row is a wallet that receives SOL.

How it pays out

pump holds the creator fees in the coin’s vault and pays the rows when its minimum is met. A keeper asks for the payout; anyone can. No signature needed.

    How it works on chain
    

      
Transaction 1: create

        
pump’s own create instruction, your wallet as creator, co-signed by a mint key the server made ahead of time. That key signs once and holds nothing after. Trades before transaction 2 pay pump’s default.

      
Transaction 2: split

        
create_fee_sharing_config, then update_fee_shares_v2 with admin_revoked. Payouts come from the creator vault; anyone can request one, no signer needed.

      
If transaction 2 fails

        
The coin exists. Keep its address and set the split later at /enroll.
